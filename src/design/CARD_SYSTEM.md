# LUA 카드 체계 (Card System)

> 모든 카드는 아래 클래스/토큰을 사용합니다. 인라인으로 색·곡률·그림자를 직접 박지 마세요.
> 값을 바꾸려면 `src/styles.css`의 `--card-*` 토큰 하나만 고치면 전체에 반영됩니다.

## 0. 카드 vs 시트 — 먼저 구분

| | **카드 (Card)** | **시트 (Sheet)** |
|---|---|---|
| 정의 | 페이지 **안에** 들어가는 콘텐츠 박스 | 화면을 **덮으며 올라오는** 패널 |
| 너비 | 좌우 여백 있음 | 풀폭 (화면 꽉 참) |
| 곡률 | 4면 둥글게 | **위쪽만** 둥글게 |
| 배경 | 흰 70% 글래스 | 더 불투명/솔리드 |
| 핸들 | 없음 | 보통 있음 (드래그 핸들) |
| 토큰 | `--card-*` | `--sheet-*` (별도) |
| 예 | 진단서 섹션, 추세 카드, 앨범 셀 | 설정 시트, 채팅 시트, 바텀시트 모달 |

→ **시트·모달에는 카드 토큰을 쓰지 않습니다.** 시트는 `--sheet-bg`, `--sheet-handle` 등 사용.

## 1. 카드 4티어

| 클래스 | 용도 | 곡률 | 배경(라이트) | 블러 | 그림자 | 패딩 |
|---|---|---|---|---|---|---|
| `.card` / `.glass-card` | **큰 카드** — 페이지 최상위 콘텐츠 | **24** | 흰 70% | 12px | `0 2px 8px /0.01` | 20 |
| `.card-nested` / `.card-flat` | **중첩** — 카드 안의 박스 | **20** | `#F1F3F5` 솔리드 | 없음 | 없음 | 16 |
| `.card-sm` | **소형** — 앨범·리스트 작은 칸 | **12** | 흰 70% | 12px | 없음 | 10·12 |
| `.card-alert` | **알림** — 시맨틱 틴트 | **20** | `--context-bg`(연블루) | 없음 | 없음 | 16 |
| `.result-section` | **진단서 섹션** | 24 | 흰 70% | 12px | `/0.01` | (자체) |

## 2. 특수: 날씨 패널

카드와 **곡률·블러·그림자·투명도(0.7)는 동일**, 배경만 블루 틴트로 차별화.
- `--card-weather-bg`: 라이트 `rgba(214,232,252,0.7)` (옅은 스카이 블루) / 다크 `rgba(120,189,253,0.06)`

## 3. 토큰 (단일 출처: `src/styles.css`)

**배경:** `--card-bg` · `--card-sm-bg` · `--card-nested-bg` · `--card-alert-bg` · `--card-weather-bg`
**블러:** `--card-blur` (라이트 `blur(12px)` / 다크 `none`)
**그림자:** `--card-shadow` (라이트 `0 2px 8px rgba(0,0,0,0.01)` — 메인 탭바 세기 / 다크 `0.3`)
**곡률:** `--card-radius`(24) · `--card-nested-radius`(20) · `--card-sm-radius`(12)
**패딩:** `--card-pad`(20) · `--card-nested-pad`(16) · `--card-sm-pad`(10·12) · `--card-alert-pad`(16)

**다크 테마 배경:** `--card-bg` 흰5% · `--card-sm-bg` 흰6% · `--card-nested-bg` 흰3%

## 4. 사용 규칙

- 새 카드 = 위 클래스(`className="card"` 등) 또는 인라인이면 `var(--card-bg)` 토큰 사용. 흰색 투명도를 직접 박지 말 것.
- **카드가 아닌 것**(칩·토글·세그먼트·입력칸·아이콘 배지·구분선·진행바·버튼·**시트/모달**)에는 카드 토큰 금지.
- 시트로 보이는데 카드처럼 된 게 있으면 → 카드 토큰 제거하고 시트 스타일(풀폭·상단만 둥글게)로 전환.


## 5. 카드 제목 타이포

카드 최상단 헤더 텍스트(카드 제목)는 **전 페이지 공통 규칙**을 따릅니다.

| 속성 | 값 |
|---|---|
| **font-weight** | **600** (`--fw-semibold`) — 예외 없음 |
| font-size | 14 (기본) / 16 (큰 카드) |
| color | `var(--text-primary)` 또는 `var(--text-secondary)` |

- 기준 구현: 진단서 `.result-section-title` (`styles.css`) = font-weight 600.
- **카드 제목에 500(Medium)을 쓰지 말 것.** 인라인이면 `fontWeight: 600`.
- 카드 밖/위의 `text-muted` 소제목(예: "측정 기록", "항목별 변화")은 카드 제목이 아닌 **하위 라벨** 티어로, 이 규칙 대상이 아님(500 유지).
