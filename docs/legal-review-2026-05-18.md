### 2.2 처리 흐름

1. **수집**: 사용자 디바이스에서 셀카 촬영
2. **외부 처리**: OpenAI L.L.C.(미국, GPT-5.2 비전 모델)에 셀카 일시 전송
3. **폐기**: 분석 응답 수신과 동시에 회사 서버 및 OpenAI 서버에서 폐기
4. **저장**: 분석 결과(점수·텍스트)만 사용자 디바이스 localStorage·IndexedDB에 저장
5. **회사 서버**: 셀카·측정 결과 영구 저장 안 함. 익명 통계(요청 수·성공률·평균 응답 시간)만 35일 보관

## 3. 검토 요청 포인트 (우선순위 순)

1. **개인정보 보호법 제23조(민감정보·생체정보) 별도 동의 요건 충족 여부**
   — 얼굴 사진은 생체정보에 해당하므로 별도 동의서를 첨부했으나, 표현·범위 적정성 검토 필요

2. **OpenAI(미국) 국외 이전 동의 절차 적정성 (PIPA 제17조·제28조의2)**
   — 현재 처리방침 4조에 "국외 이전에 대해서는 별도 동의를 받음" 명시. 별도 동의서 양식이 필요한지

3. **"측정 결과는 의료 진단·치료 목적이 아니다"는 면책 조항의 법적 효력**
   — 이용약관 6조 면책 범위가 충분한지, 보강 필요 표현 식별

4. **베타 서비스 특칙(시험 단계, 사전 고지 없는 변경, 데이터 처리 범위) 적정성**
   — 이용약관 7조. 베타 사용자에게 정식 출시 전 데이터 이관 별도 동의 명시

5. **미성년자(만 14세 미만) 처리 조항 보강 필요 여부**
   — 현재 이용약관 5조에서 "보호자 동의 없이 미성년자 이용 금지" 명시. 가입 차단 기술적 조치 필요 여부

6. **분쟁 해결·관할 법원·준거법 표준성**
   — 이용약관 9조

7. **부족한 조항 또는 보강 필요 항목 식별**
   — 환불·해지·서비스 종료·정보 보안 사고 통지·이용자 책임 등
